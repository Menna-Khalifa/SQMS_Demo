# SQMS Interactive Demo v2

Interactive static demo for the Security Quality Management and Field Inspection system.

## Language
Use the language button in the top bar to switch the full interface between Arabic RTL and English LTR.

## Recommended demo flow
1. Start as Quality Inspector: open Schedule -> Field Inspection -> save a draft -> upload evidence -> submit.
2. Switch to Quality Management: open Review & Approval -> return/reject/approve.
3. Switch to Project Manager: verify only Al Waha project is visible and analytics are scoped.
4. Switch to Guard Supervisor: evaluate guards and open Training Requests.
5. Switch to Security Guard: open the private survey/complaint/sensitive-report channel.
6. Return to System Owner: grant/revoke independent sensitive-report permission, run Permission Tests, inspect Attachment Policy, Audit Log and Backup/Restore.
7. Open Demo Guide for the full requirement coverage map and suggested demo accounts.

## Demo scope
The demo represents the requested UI, workflows, permissions, form versioning, scoring, review lifecycle, corrective actions, training, sensitive reports, report preview, analytics, registration/undertaking, attachment policy, audit, backup/restore and bilingual responsive behavior using mock data.

It is a static HTML/CSS/JS demonstration. Production security requires the Laravel/MySQL backend described in the project scope: authentication, Policies/Scopes, private storage, database persistence, encryption, real backup/restore, SMTP and server-side PDF/Excel generation.
